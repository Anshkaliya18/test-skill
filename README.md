# Claude Resume Commands

3 simple, beginner-friendly slash commands for [Claude Code](https://docs.anthropic.com/claude/docs/claude-code) to create, update, and improve your resume in seconds. 

## Commands

| Command | Description |
| :-- | :-- |
| `/resume-make` | Create a brand new `resume.md` from scratch by answering a few quick questions. |
| `/resume-update` | Edit your existing `resume.md` with minimal changes based off of what you want to update. |
| `/resume-suggest` | Get up to 5 actionable, high-impact suggestions to improve your resume. |


## Installation

Install these globally once and you'll be able to use them in any project you open with Claude Code. 

### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/AnshKaliya18/test-skill/main/install.sh | bash
```

## Windows (PowerShell)
```bash
irm https://raw.githubusercontent.com/AnshKaliya18/test-skill/main/install.ps1 | iex
```
